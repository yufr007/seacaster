# SeaCaster V2

Active runtime: App.tsx, app/, game/, backend/src/, contracts/. Use React 18, React Three Fiber 8, Vite, TypeScript, a single REST API and PostgreSQL. Do not introduce Unity, React Native, another engine, a monorepo framework, paid-entry competitions, a fungible token, B20 or a marketplace without a concrete requirement.

The supplied reboot plan authorizes replacing obsolete Farcaster/FID assumptions. There are no production users or migration obligations. Existing fish artwork, names and nautical identity are retained. Do not fabricate chain deployments, successful purchases, leaderboard players, test results or production readiness.

Game rules are pure in game/. React is presentation. Authenticated progress is authoritative on the server. Guest saves are local practice and never imported as trusted online progress. Catch completion is replayed and awarded atomically once. Purchases are confirmed onchain; never persist a local premium flag as authority.

Run npm test, npm run build, npm run test:api with a disposable PostgreSQL DATABASE_URL, npm run test:e2e, and contract tests before release. Browser screenshots and real device checks remain distinct from compiling successfully. Do not deploy to mainnet or move funds implicitly.

Read docs/REVAMP.md and docs/RELEASE.md for current scope and verification. Historical implementation material is not a second active application.
