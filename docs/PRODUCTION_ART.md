# SeaCaster production-art pass

## Approved target

Replace the flat blockout presentation with a cohesive stylized mobile fishing world. Reference qualities: sculpted silhouettes, deliberate proportions, warm edge highlights, material separation, readable gestures and expressive motion. Do not copy Supercell assets or promise a chart position. Keep React 18/R3F 8/Three r160/Vite and all existing fishing, wallet, progression and payment rules.

## Work in this branch

1. Author an original Blender kit with continuous curved hulls, softened timber, paint/wood material textures, smooth normals, curved vegetation, an expressive morph-animated reef fish and named interaction pivots. Export self-contained GLB. Test UVs, textures, animation, required pivot names and payload budgets before integration.
2. Replace the runtime blockout platforms, islands, wildlife, chest, float and rod with cached GLB models. Keep the existing line/cast target math, pointer input, bait selector and local-time clock. Clone animated instances while sharing immutable geometry/materials.
3. Establish explicit sRGB output, controlled physical lighting, bounded soft shadows and environment reflections. Keep effects subordinate to touch readability; no screen-space blur or mandatory heavy postprocessing.
4. Run domain/API/contract/browser regressions and inspect phone-sized daytime/nighttime and all-platform renders. Verify texture failures fall back honestly and that no authoring file is shipped in the public build.

## Art provenance and limits

The asset generator creates original scripted Blender meshes and procedural paint textures. They are not purchased art, not a hand-sculpted studio commission, and not claimed to be AI-generated. Fal was suggested for a future generated-3D art source, but is not connected in this session. Image-generation concept art is unavailable here; the approved written direction and before/after browser renders are the visual review basis.

The generic reef fish is ambient/anonymous fight art, not a replacement for all fifteen species portraits. Their catalogue identities and catch portraits remain intact. The new kit is a production-format candidate; artistic approval, species-specific hero assets and physical-phone frame-time/thermal testing remain separate gates. Tests alone do not certify AAA visual quality.

No engine migration, React Native port, new economics, new database or onchain deployment is part of this pass. Main must not be merged or deployed implicitly.
